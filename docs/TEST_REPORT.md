# AI LAB 0.2 — отчет о тестировании

Дата: 17.11.2026

- Smoke test симуляции: 40 матчей из 40 завершились без аварий и без неверных координат.
- Среднее число голов: 8.9 на матч 5 на 5 (слишком высокая/неотрегулированная результативность, дальнейшая настройка обязательна).
- Среднее число ударов: 28.2 на матч, передач: 142.2, нарушений: 7.3.
- Срабатывания QTE при автоматизированном выборе действий: 13.0 на матч. Эта оценка не подтверждает оптимальную частоту для человека.
- Browser smoke: открытие поля, атака с жестом, QTE отбор, изменение пассивных установок; ошибок JavaScript не обнаружено.
- Mobile smoke: рендеринг горизонтального размера 844×390 в Chromium; не является испытанием на физическом iPhone.

Текущая симуляция служит тестом архитектуры и не претендует на статистическую реалистичность. На следующем этапе балансировать ожидаемые голы, качество решений, вратарей, стандарты и частоту нарушений. Тесты с реальными игроками еще не проводились.
