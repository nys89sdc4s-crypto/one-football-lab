# ONE / FOOTBALL — AI LAB 0.2

Ранний эксперимент непрерывного футбольного матча 5 на 5 в браузере. Цель: проверить самостоятельный игровой ИИ, движение мяча и короткие контекстные QTE до разработки полноценной iOS-игры.

## Играть

**GitHub Pages:** https://nys89sdc4s-crypto.github.io/one-football-lab/

Адрес заработает после однократного включения GitHub Pages в **Settings → Pages → Build and deployment → Source → GitHub Actions** и успешного выполнения workflow. Если ссылка возвращает 404, проверьте вкладку **Actions** и настройки **Pages**.

Альтернативно откройте `index.html` в браузере на компьютере.

## Содержимое

- `index.html` — исполняемый прототип, стили, графика, физика и ИИ внутри одного файла.
- `docs/DEV_DIARY.md` — дневник разработки и утвержденные решения по игре.
- `docs/TEST_REPORT.md` — технические проверки версии 0.2 и известные недостатки.
- `.github/workflows/pages.yml` — автоматическая публикация сайта при коммитах в `main`.

## Что проверить в игре

Наблюдайте за перемещениями игроков, качеством передач, прессингом и нарушениями. Попробуйте менять активность и зону своего игрока, участвовать в QTE. Оценивайте не только ошибки, но и разнообразие игровых эпизодов.

Версия 0.2 не гарантирует реалистичную результативность. Это исследовательский прототип, не готовый симулятор 11 на 11 и не нативное приложение iOS.

## Публикация

Workflow в `.github/workflows/pages.yml` выполняется после каждого push в `main`. Настройка источника Pages через GitHub Actions делается один раз в интерфейсе GitHub. После этого обновления исходников разворачиваются автоматически без ручной загрузки на хостинг.

## Дальнейшая разработка

1. Повысить качество пространственного ИИ и поведения вратарей.
2. Уточнить физику мяча, единоборства и стандарты.
